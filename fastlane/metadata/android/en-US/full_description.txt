Pass derives strong, repeatable passwords on your device. The same site, login, master password, and settings always produce the same result, so there is no password database to back up, sync, or lose.

Everything is computed locally. The app makes no network requests, keeps no accounts, and tracks nothing.

Features:

• Deterministic, LessPass-compatible password generation
• Configurable length, counter, character classes, and excluded characters
• Optional fingerprint unlock with the master password held in secure storage
• No analytics, no tracking, no network access

Pass is an independent implementation of the LessPass algorithm. Compatibility does not imply endorsement by or affiliation with the LessPass project.
