A few things to know

Before you begin.

Is Pass a password manager?

Pass is a stateless generator. It recreates a password from your inputs instead of storing a vault of passwords. App profiles can help you remember site settings; they are separate from password generation.

What must I remember?

Your master password and the exact site, login, and generation settings. A change to any input changes the output. There is no master-password reset service.

How do I change a generated password?

Increase the counter in the app, then change the password at the service too. Keep the new counter with your other site settings so you can recreate that password later.

Does this work with LessPass?

Pass is an independent implementation of the LessPass generation algorithm. Matching inputs and compatible settings produce the same result. Pass is not affiliated with or endorsed by the LessPass project.
