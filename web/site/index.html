Features

Small by design.

Deterministic

Generate the same password from the same site, login, master password, and settings.

Local-first

No password database, no sync account, no analytics, and no network service required for generation.

Portable

Use the same generator across Android, desktop, terminal, and web builds.

Open source

Source and releases remain available under BSD-3-Clause.

Privacy

Your master password stays yours.

The desktop and browser apps derive passwords locally. The website has no analytics, accounts, cookies, or backend API.
